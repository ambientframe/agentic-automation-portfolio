# Start Here

This folder contains the canonical handoff for a new ChatGPT Project.

## Files

- `PROJECT_HANDOFF.md` — comprehensive project strategy, architecture, progression, guardrails, and immediate build sequence.
- `CHATGPT_PROJECT_INSTRUCTIONS.md` — paste this into the ChatGPT Project's custom instructions.

## Recommended Setup

1. Create a new ChatGPT Project.
2. Add `PROJECT_HANDOFF.md` to the project files.
3. Paste the contents of `CHATGPT_PROJECT_INSTRUCTIONS.md` into the Project Instructions field.
4. Start the first project chat with a request to inspect the handoff and begin by defining/building the Portfolio Flight Simulator and six-system destination shell.

The first implementation target should remain Lead Rescue, but the final six-system portfolio should remain visible from the beginning.
